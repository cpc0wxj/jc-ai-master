大家好，鸡哥来了。

先说说鸡哥为什么要做这门课。

去年开始，鸡哥发现身边不少 Java 程序员都在问同一个问题：AI 这么火，我到底该怎么学？然后去找课，找到的要么是 Python 课，要么是算法课，要么是理论讲一堆但代码一行都跑不起来的课。

专门给 Java 程序员做的、能真正落地的 AI 应用开发课，几乎没有。

市面上是有一些课，但质量层次不齐——有的内容是外包出去写的，讲师自己都没深入做过；有的直接把开源项目包装一下当课程卖，代码能跑，但跟公司真实业务完全脱节；还有的堆了一大堆知识点，学完之后回到工作里，还是不知道从哪下手。实际在公司能直接用的，一个没有。

所以鸡哥做了这门课。

鸡哥自己探索 AI 的过程，大概经历了这几个阶段：

最早是 ChatGPT 刚出来那会儿，觉得好玩，围绕 GPT 做了一些小机器人，自动回复、关键词触发这类，纯粹是玩。

后来开始研究 Prompt，发现提示词写得好不好，输出结果差距极大，花了一段时间专门研究怎么从模型里问出想要的东西。

再后来是在实际项目里调 API，给已有的系统加 AI 能力——搜索变智能搜索、报表加上自动分析、客服接入大模型。这一步才开始真正感受到 AI 在工程上的复杂度。

然后是直接起新项目，从零开始用 Agent 来赋能业务流程，把原本需要人工干预的多步骤任务，交给 Agent 自动完成。

这个过程踩了不少坑，也积累了很多在文档和视频里看不到的东西。这门课，就是鸡哥把这些阶段里真正有用的东西整理出来，系统地教给大家。

不是 Python 课，不是教大家怎么底层算法的课，也不是那种标题很大但内容全是文档搬运的课。

## 能学到什么

**理论层面**，大家会真正搞懂那些听着玄乎的词——Token、Embedding、RAG、Agent、MCP 到底是什么，AI 应用的完整架构是怎么设计的，面对一个需求该怎么选模型、选框架、选技术方案。

**工程层面**，主要围绕三个 Java AI 框架来展开：

- **Spring AI**：Spring 官方出品，和 Spring Boot 无缝集成，做企业级 AI 功能首选
- **LangChain4j**：Java 版 LangChain，功能完整，Tool Calling、Memory、RAG 都有覆盖
- **AgentScope**：开源的 Java 多 Agent 框架，专门为复杂 Agent 协作场景设计，课程里会重点讲


学完之后，大家能独立构建 RAG 知识库系统、能开发 Agent 自动化流程、能接入 MCP 协议、能用 Vibe Coding 提升日常开发效率。

更重要的是——大家能把这些能力真正用到工作里：

- **改造老项目**：给现有的 Spring Boot 系统加入 AI 能力，比如智能搜索、自动摘要、对话式查询，不用推倒重来
- **成为团队里的 AI 先行者**：当公司开始布局 AI 的时候，大家是那个能直接上手做的人，而不是在旁边看别人做
- **推动 AI 落地**：很多公司不是不想用 AI，是没人能做。大家学完了，就是那个把想法变成真实系统的人
- **简历含金量提升**：AI 应用开发经验、RAG 系统、Agent 开发这些词出现在简历里，跟没有这些经历完全是两个竞争段位

## 学完能做哪些项目

课程里会做三个完整项目，不是 Demo，是能改改就用的东西：

**项目一：企业知识库问答系统（实战级）**
员工上传产品手册、规章制度，系统自动建立索引，员工用自然语言提问，系统给出准确答案并附上出处。这个场景在企业里需求极大，很多公司都在做这件事。

**项目二：业务自动化 Agent（实战级）**
输入一句话"帮我生成上个月华东区的销售分析报告"，Agent 自动查询数据库、计算指标、生成图表、发送邮件，全程不需要人工干预。

**项目三：语音导购 Agent（实战级）**
用户说"我想买一双适合跑步的鞋，预算 500 以内"，Agent 实时理解语音、检索商品库、匹配需求、主动推荐，全程像真人导购一样对话。
